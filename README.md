# 订单保本线 Lite

单 SKU 免费离线版，用来快速估算国内小电商订单在退款、退货货损、双向物流、
平台费和广告成本后的每下单贡献利润。

## 适合

- 想判断一个 SKU 在退款后是否还赚钱；
- 想估算保本售价、最高广告成本和当前 ROAS 压力；
- 想在不上传经营数据的情况下先做快速测算。

## 不适合

- 税务申报、财务审计或会计净利润核算；
- 自动读取店铺后台、平台账单或订单明细；
- 承诺收益、广告投放建议或投资判断。

## 隐私

本工具是浏览器里的静态页面，不需要登录，不上传数据，不内置平台账号接口。
所有价格、成本、费率和退款率都只在当前浏览器页面中计算。
